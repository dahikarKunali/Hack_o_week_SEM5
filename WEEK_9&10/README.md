# Week 9 & 10 - Hack-o-week

## Student Performance Analysis

This project focuses on evaluating a machine learning model for student performance prediction.

## Topics Covered

- Train/Test Split
- Cross-Validation
- Confusion Matrix
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- ROC Curve
- Feature Engineering
- Feature Scaling
- Missing Data Handling
- Feature Importance

## Machine Learning Model

Random Forest Classifier

## Preprocessing

- Missing values are handled using median imputation.
- Features are scaled using StandardScaler.
- New features such as Average Score and Study Efficiency are created.

## Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- 5-Fold Cross-Validation
- Confusion Matrix

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Conclusion

The project demonstrates the complete machine learning evaluation process, from data preprocessing and feature engineering to model training and performance evaluation.
